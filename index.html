인형이랑 수학 놀이

4~5세 아이가 애착인형과 함께
1부터 100까지 수를 놀면서 익혀요.

처음에 준비해요

  • 애착인형 사진 1~5장 찍기 (없어도 돼요)
  • 인형 이름 정하기

놀이는 8단계예요

이렇게 배워요

  • 아이들이 수를 익히는 순서(학습 경로)대로 바로 알기 → 세기 → 비교 → 규칙 → 더하기·빼기 → 큰 수로 이어져요.
  • 물건 → 그림 → 숫자 순서로, 그림을 보며 셀 수 있게 했어요.
  • 글자를 몰라도 되게 모든 문제를 소리로 읽어 줘요.
  • 틀리면 응원 → 반짝 힌트 → 같이 세기 순서로 도와줘요.
  • "똑똑해" 대신 "끝까지 잘했어"처럼 노력을 칭찬해요.

버튼 색깔 약속

  • 파란 동그라미 = 다음 놀이 (오른쪽)
  • 주황 동그라미 = 한 번 더 (왼쪽)
  • 그림·글자 없이 색깔로만 알아보게 했어요. 처음엔 같이 눌러 주세요.

부모님께

  • 옆에서 같이 세어 주시면 훨씬 잘 배워요.
  • 하루 10분이 지나면 인형이 "졸려요" 하고 쉬어요. (부모님 메뉴에서 끌 수 있어요)
  • 처음 화면 아래 버튼을 2초 꾹 누르면 단계 열기, 인형 바꾸기를 할 수 있어요.
  • 사진은 이 휴대폰에만 저장되고 어디에도 올라가지 않아요.
  • 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.
